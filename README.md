# 메이즈 이스케이프

미로를 돌며 점을 다 먹으면 다음 판으로 넘어가는 브라우저 게임입니다.
도깨비 넷이 쫓아오고, 큰 점을 먹으면 잠깐 동안 거꾸로 잡을 수 있습니다.

<https://meins-maze-escape.netlify.app>

## 조작

| | |
|---|---|
| 키보드 | 방향키 또는 WASD |
| 터치 | 화면을 원하는 방향으로 밀기 |

벽에 막히면 멈추지 않고 왼쪽이나 오른쪽으로 저절로 꺾습니다. 제자리에 서 있을 수 없습니다.

## 진행

- 레벨 1부터 5까지 있습니다. 레벨마다 맵과 벽 색이 바뀌고, 조금씩 빨라집니다.
- 레벨 5를 깨면 엔딩입니다.
- 도깨비는 각자 역할이 있습니다. 바로 뒤를 쫓는 녀석, 앞길을 막는 녀석, 둘이서 앞뒤로 가두는 녀석, 다가왔다 물러났다 하는 녀석.
- 잡힌 도깨비는 눈만 남아 집으로 돌아가고, 3초 쉰 뒤 다시 나옵니다.

## 개발

```bash
yarn install
yarn dev
yarn lint
yarn check   # 모든 맵 검사
yarn build
```

Vite와 TypeScript, 캔버스만 씁니다. 외부 라이브러리는 없습니다.

기여 방법은 [CONTRIBUTING.md](./CONTRIBUTING.md)에 있습니다.
